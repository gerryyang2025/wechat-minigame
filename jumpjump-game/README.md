# jumpjump-game

`jumpjump-game` 是一个微信小游戏版本的跳一跳：玩家长按蓄力、松手起跳，通过控制力度让棋子落到下一个方格上，连续命中中心区域可以获得更高分数。

## 功能特性

- 长按蓄力、松手跳跃，蓄力节奏偏慢，便于控制力度。
- 蓄力时显示粒子特效、音效反馈、瞄准线与方格压扁效果。
- 支持在首页切换是否显示瞄准线，默认开启。
- 方格按远近错落生成，包含近距离与远距离跳跃。
- 不同方格拥有不同奖励分数，中心命中和连击会进一步加分。
- 游戏过程中保留已生成且仍在视野内的方格，形成连续的路径观感。
- 首页、玩法说明、排行榜、结算页和清空成绩入口完整可用。
- 本地保存历史成绩、最佳记录、已玩局数，并在排行榜中显示日期和时分秒。
- 结算页展示本次得分、最佳记录、成功跳跃次数和本机排行。

## 视觉设计

- 竖屏全屏画布，适配微信小游戏常见手机比例。
- 首页使用铺满屏幕的背景图，并展示三个不同样式的彩色方格。
- 标题文字直接叠加在场景上，不使用灰色底板。
- 首页底部只保留排行榜入口，避免无效功能干扰。
- 游戏主界面采用浅灰蓝背景、等距视角方格和柔和阴影。
- 提示文字、连击文字和加分文字使用更清晰醒目的颜色。
- 失败结算弹窗采用深色半透明面板，排行榜列宽固定，便于对齐阅读。

## 目录说明

- `game.js`：小游戏入口。
- `game.json`：微信小游戏运行配置。
- `project.config.json`：微信开发者工具项目配置与上传忽略规则。
- `src/minigame-app.js`：微信生命周期、触摸事件和画布初始化。
- `src/minigame-runtime.js`：核心玩法、方格生成、碰撞判定、渲染循环和页面状态。
- `src/game-meta.js`：游戏说明、提示文案和排行榜展示配置。
- `src/platform-assets.js`：方格图片资源映射表。
- `images/`：运行时使用的背景、角色、方格和界面图片。
- `audio/`：蓄力、跳跃、得分和失败等音效。
- `scripts/validate.js`：本地校验脚本。

## 本地校验

```bash
node scripts/validate.js
```

校验会检查核心脚本、JSON 配置、资源引用和上传包体积估算，提交或上传前建议先执行一次。

## 注意事项

- 真机触摸问题需要优先在手机端验证，不能只依赖 macOS 模拟器表现。开发者工具中长按、松手正常，不代表手机端的触摸事件、时间戳和音频行为完全一致。
- 蓄力计时不要混用不同时间源。触摸开始时记录的 `utils.now()` 与 `requestAnimationFrame(timestamp)` 在真机上可能不是同一个起点，混用会导致蓄力时间被计算为负数或始终为 0。
- 当前蓄力逻辑使用每帧 `deltaTime` 累加 `chargeElapsed`，这样可以避免真机 RAF 时间戳差异导致“有音效，但目标线不增长、松手不跳跃”的问题。
- 游戏进行中长按屏幕任意位置都应进入蓄力，不应依赖舞台坐标命中判断。菜单、玩法说明和结算页仍按按钮区域处理点击。
- 修改触摸、蓄力、目标线或音效逻辑后，建议同时检查：按下是否播放蓄力音效、目标线是否随蓄力变长、松手是否停止蓄力音效并开始跳跃。
- 真机预览前建议重新编译，并在微信开发者工具中清理缓存后再测试，避免手机端运行旧包。

## 运行方式

1. 使用微信开发者工具导入 `jumpjump-game` 目录。
2. 如需本地私有配置，复制 `project.private.config.example.json` 为 `project.private.config.json`。
3. 在开发者工具中编译运行。
4. 上传前执行本地校验，确认资源体积和配置无异常。
