# 方块破坏王

这是一个微信小游戏打砖块原型。当前版本以自定义关卡作为核心玩法，同时提供十关默认挑战路线。游戏使用 Three.js/WebGL 呈现 3D 砖块、弹球、挡板、道具和发光特效，UI 通过 CanvasTexture 合成到 WebGL 画面中，整体视觉采用漫画书手绘风。

## 核心玩法

- 默认只有 1 颗白色弹球，玩家按住屏幕拖动瞄准，松开手指后发射。
- 瞄准线使用虚线显示，会延伸到首次碰撞点，并显示一次反弹后的预测路线。
- 弹球会在墙体、砖块和挡板之间反弹，击中绿色普通砖和技能砖会消除砖块。
- 玩家左右拖动下方挡板接球；弹球只有掉出底部且挡板没有接到时才会被移除。
- 托板使用相对拖拽控制，手指按下时不会立刻跳到触点位置；拖动时会按大于 1 的倍率跟随，快速滑动会获得更高移动倍率。
- 每局默认有 `3` 条命，全部弹球掉出底部且未清空砖块时扣 1 条命，生命归零后挑战结束。
- 关卡使用固定棋盘设计，不会从上方生成补行，也没有底部危险线推进规则。
- 默认挑战关卡采用十关制：第 1-5 关是低难度道具教学关，分别只使用分裂、重弹、霰弹、炸弹、激光一种技能砖。前五关以技能砖作为主要目标，技能砖数量更密集，普通绿砖只保留少量对照，帮助玩家在短时间内多次触发同一道具并理解用途，而不是把重点放在清理普通绿砖上；第 6-10 关开始进入复合关卡，可以同时出现多种道具，并通过不同墙体节奏和空位结构逐步提升清除压力。默认关卡布局以 `src/default-levels.js` 和默认关卡编辑器为准，运行时不会再开墙、清砖或转换地图。
- 击碎最后一块可破坏砖后会进入短暂慢动作，最后一块砖在原位缩放、旋转、淡出并播放擦除粉尘；第 1-9 关结束后可进入 `下一关`，第 10 关结束后显示最终 `关卡完成`。

## 关卡与界面

- 自定义关卡作为核心玩法，首页主入口是 `自定义关卡`，`挑战默认关卡` 用于试玩十关默认挑战路线，`默认关卡编辑器` 可进入默认模板编辑器。
- 首页顶部只显示独立游戏名称文字，不使用 HUD 或卡片承载。
- 游戏中页面顶部不显示关卡、计时等额外 HUD 信息，避免挤压棋盘视野。
- 玩法说明入口只保留在首页，战斗界面底部不再显示额外说明按钮。
- 战斗界面底部信息条左侧提供 `结束游戏` 小按钮，可停止当前局、清理场上弹球和道具，并返回游戏首页；按钮收在信息条内部，计时、关卡、生命和弹球数使用双行分区布局，避免互相遮挡或遮挡托板。
- 小程序分享卡片使用固定摘要 `方块破坏王 自定义地图，设计自己的玩法`，突出自定义地图核心玩法。
- 战斗中的持续状态提示使用底部信息条边侧小标签，例如 `重型弹` 剩余时间显示在右上侧，避免和底部挡板处于同一水平视觉焦点。
- 结算面板展示本局用时、发射次数、击碎方块和收集道具；用时精确到秒，避免重复显示结果状态。

## 砖块与道具

- 绿色普通砖在复合关卡和自定义关卡中是主要消除目标；前五个道具教学关会刻意减少绿色砖，把画面重点让给对应技能砖。
- 灰色墙体默认只负责反弹弹球；金色重弹可以击碎内部灰墙，但棋盘边界墙仍不可破坏，避免弹球飞出场外。
- 蓝、金、紫、红、粉五种技能砖会稳定掉落对应道具；绿色普通砖不会掉落道具。
- 分裂：按当前弹球生成额外弹球，增加当前回合弹球数量。
- 重弹：短时间提升弹球体积和伤害，并立即强化场上已有弹球；计时结束后弹球恢复普通状态，强化期间可以击碎内部灰墙。
- 霰弹：从挡板位置额外发射多颗弹球。
- 炸弹：只清理落点砖块和上下左右相邻砖块，避免一次扫掉过大区域。
- 激光：清理挡板正上方一列砖块。
- 彩色技能砖与道具一一对应：蓝色分裂、金色重弹、紫色霰弹、红色炸弹、粉色激光。
- 炸弹、激光等道具清理技能砖时不会继续生成二次道具，避免连锁掉落堆满屏幕。
- 自定义关卡与默认模板共用同一套掉落规则，场上可同时存在的下落道具数量有限制；超过显示上限的道具会进入延迟掉落队列，等前面的道具被接住或离开后再出现，不会移除正在下落的可见道具。当前回合白球归零后会清空场上道具和延迟队列，立即进入扣命或下一次发射流程。

## 局内规则

- 每个关卡开始时都回到初始发射状态：固定 `1` 颗白色弹球、普通伤害和基础挡板宽度。
- 击碎砖块只更新击碎统计；本局表现以完成用时、发射次数、击碎方块和收集道具衡量。
- 分裂、霰弹、重弹等道具只影响当前回合；进入下一关或重新开始时都会恢复初始状态。
- 本地保存自定义关卡设计和默认模板编辑结果，不保存跨局成长数据。

## 自定义关卡

- 编辑器支持放置绿色普通砖、五种技能贴纸砖和灰色墙体。
- 技能工具使用与玩法说明、下落道具一致的漫画贴纸图标，玩家能直接识别每种特殊砖的效果。
- `擦` 工具可以清除格子。
- 内置默认关卡地图保存在 `src/default-levels.js`，使用 25 列 x 22 行 ASCII 地图描述：`#` 表示灰墙，`G` 表示绿色普通砖，`B/Y/V/R/P` 分别表示分裂、重弹、霰弹、炸弹、激光技能砖，`.` 表示空位。直接修改配置即可调整默认关卡布局；运行时会根据关卡配置签名和模板版本识别源码变化，旧的本地默认模板缓存不会继续覆盖新配置。
- 默认模板也可以进入编辑器，支持在第 1-10 默认关之间切换，手动改砖后保存；保存后 `挑战默认关卡` 会使用玩家编辑过的默认模板，新版内置模板会自动避开旧缓存覆盖；进入编辑器、保存、导出配置和开局都保留当前网格原样，不做隐藏规则转换。
- 默认模板编辑器提供 `导出配置`，会把当前编辑后的地图转换为 `src/default-levels.js` 可直接替换的关卡对象，写入本地调试缓存 `brick_breaker_exported_default_level_v1`，并在开发者工具 Console 输出。小游戏运行时不能直接写入项目源码，也不使用剪贴板 API，因此同步到配置文件需要在开发环境中复制控制台片段后粘贴。
- 编辑器所有操作按钮都集中在底部控制台，包括 `返回游戏`、`清空`、`保存`、`挑战`，以及默认模板的 `保存默认`、`导出配置`、`试玩默认` 等操作。
- 底部操作按钮统一使用标题页同款漫画书按钮样式，保证全局视觉一致。

## 美术设计

- 主画面使用低视角 3D 方块表现，但整体包装成漫画书手绘风。
- 背景使用纸张纹理，UI 叠加细颗粒、斜向手绘线和网点阴影，让画面像画在纸上的动态漫画。
- 砖块是带粗黑描边的 3D Box，密集棋盘中保持规整正方形单元。
- 绿色普通砖使用柔和草绿色和少量共享色阶，降低大面积纯亮绿色带来的突兀感。
- 方格被消除时会立即从 Three.js 场景中移除，并播放纸色擦除粉尘和漫画爆线效果。
- 技能砖直接使用对应下落道具的同款漫画贴纸图标作为砖块外观，不再额外包一层彩色方块。
- 弹球使用面向镜头的清晰圆形贴片和贴近主体的黑色漫画描边，避免高速移动时出现低分段球体边缘残影。
- 下落道具由 Canvas 程序手绘为漫画贴纸图标，再作为 Three.js 透明贴图显示。
- `玩法说明` 页中的技能说明也使用同一套漫画贴纸图标，和技能砖、下落道具保持一致。
- 标题页、玩法说明、结算页和编辑器中的文字按钮统一使用同一套漫画书按钮规格，包括高度、圆角、黑色描边、阴影偏移和字体重量。

## 技术设计

- 使用 Three.js r162 和微信 Canvas 作用域适配器创建渲染环境，避免直接依赖浏览器 DOM。
- 使用 `THREE.WebGLRenderer`、`OrthographicCamera` 和 `CanvasTexture` 组合渲染 3D 场景与 2D UI。
- 弹球与砖块使用连续碰撞检测，按运动线段判断命中，避免高速弹球穿过灰色墙体或窄砖块。
- 弹球包含防卡死机制，连续墙体反弹或长时间困在小范围内时会自动纠偏，不会直接删除场内弹球。
- UI 画布使用独立高清像素比，并按状态变化、瞄准变化、消息变化和数值变化进行按需上传。
- 主循环按状态主动降帧：有弹球、道具、瞄准或完成动画时保持约 `60fps`，标题、说明、编辑和结算等静态页面降低刷新频率。
- Three.js 关闭对象排序，场景依靠固定层级组织渲染顺序，减少密集砖块网格每帧排序开销。
- 砖块使用共享几何体和材质；球体碰撞通过行列索引只检测运动轨迹附近的砖块，避免多球时每步扫描全场。
- 擦除粉尘和爆圈特效设置了同时存在数量上限，避免炸弹、激光等连锁清理时堆积过多临时网格和材质。

## 音频设计

- 背景音乐使用微信小游戏音频接口循环播放，开始一局时启动，胜利或失败进入结算时停止；第 10 关使用独立的终局背景音乐。
- 交互音效由 Web Audio API 实时合成，不依赖额外短音效资源。
- 射击、瞄准、挡板接球、墙体反弹、砖块破碎、道具掉落、道具触发、炸弹、激光、关卡完成、编辑器放置和失败都有对应反馈。
- 高频事件带有播放节流，避免多球连撞时声音堆叠过载。

## 玩法说明设计

- 玩法说明页独立展示，不覆盖战斗画面。
- 说明内容覆盖瞄准、生命、灰墙反弹、普通砖消除、复杂技能、自定义关卡和失败条件。
- 说明文字会自动换行，避免在竖屏设备中溢出或遮挡按钮。
