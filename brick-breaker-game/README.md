# 方块破坏王

这是一个微信小游戏打砖块原型。当前版本以自定义关卡作为核心玩法，默认关卡只作为初始练习模板。游戏使用 Three.js/WebGL 呈现 3D 砖块、弹球、挡板、道具和发光特效，UI 通过 CanvasTexture 合成到 WebGL 画面中，整体视觉采用漫画书手绘风。

## 核心玩法

- 默认只有 1 颗白色弹球，玩家按住屏幕拖动瞄准，松开手指后发射。
- 瞄准线使用虚线显示，会延伸到首次碰撞点，并显示一次反弹后的预测路线。
- 弹球会在墙体、砖块和挡板之间反弹，击中绿色普通砖和技能砖会消除砖块。
- 玩家左右拖动下方挡板接球；弹球只有掉出底部且挡板没有接到时才会被移除。
- 每局默认有 `3` 条命，全部弹球掉出底部且未清空砖块时扣 1 条命，生命归零后挑战结束。
- 关卡使用固定棋盘设计，不会从上方生成补行，也没有底部危险线推进规则。
- 击碎最后一块可破坏砖后会进入短暂慢动作，最后一块砖在原位缩放、旋转、淡出并播放擦除粉尘，再显示 `关卡完成`。

## 关卡与界面

- 自定义关卡作为核心玩法，首页主入口是 `自定义关卡`，`体验默认关卡` 仅用于试玩初始模板。
- 首页顶部只显示独立游戏名称文字，不使用 HUD 或卡片承载。
- 游戏中页面顶部不显示关卡、分数、炮台等额外 HUD 信息，避免挤压棋盘视野。
- 玩法说明入口只保留在首页，战斗界面底部不再显示额外说明按钮。
- 小程序分享卡片使用固定摘要 `方块破坏王 自定义地图，设计自己的玩法`，突出自定义地图核心玩法。
- 战斗中的持续状态提示使用底部信息条边侧小标签，例如 `重型弹` 剩余时间显示在右上侧，避免和底部炮台/挡板处于同一水平视觉焦点。
- 结算面板展示本局得分、发射次数、击碎方块、获得经验、收集道具和本局最高炮台等级，避免重复显示结果状态。

## 砖块与道具

- 绿色普通砖是主要消除目标，占默认关卡的绝大多数。
- 灰色墙体不会被消除，只负责反弹弹球。
- 蓝、金、紫、红、粉五种技能砖会稳定掉落对应道具；绿色普通砖不会掉落道具。
- 分裂：按当前弹球生成额外弹球，增加当前回合弹球数量。
- 重弹：短时间提升弹球体积和伤害，并立即强化场上已有弹球。
- 霰弹：从挡板位置额外发射多颗弹球。
- 炸弹：对附近砖块造成范围破坏。
- 激光：清理挡板正上方一列砖块。
- 彩色技能砖与道具一一对应：蓝色分裂、金色重弹、紫色霰弹、红色炸弹、粉色激光。
- 炸弹、激光等道具清理技能砖时不会继续生成二次道具，避免连锁掉落堆满屏幕。
- 自定义关卡与默认模板共用同一套掉落规则，场上可同时存在的下落道具数量有限制，避免道具爆量影响性能和可读性。

## 成长规则

- 首次进入默认模板或自定义挑战时，炮台 `Lv.1`、`1` 颗白色弹球开始。
- 击碎砖块会获得本局分数和本局经验。
- 经验条蓄满后会自动升级炮台，不再提供手动升级按钮。
- 自动升级炮台会逐步增加发射弹球数量、提升弹球伤害，并略微增加挡板宽度。
- 分数、经验、炮台等级、弹球数量和挡板强化都只在本局有效，胜利或失败进入结算后重置。
- 本地仅保存自定义关卡设计，不保存跨局成长数据。

## 自定义关卡

- 编辑器支持放置绿色普通砖、五种技能贴纸砖和灰色墙体。
- 技能工具使用与玩法说明、下落道具一致的漫画贴纸图标，玩家能直接识别每种特殊砖的效果。
- `擦` 工具可以清除格子。
- 编辑器所有操作按钮都集中在底部控制台，包括 `返回主页`、`清空`、`保存` 和 `挑战`。
- 底部操作按钮统一使用标题页同款漫画书按钮样式，保证全局视觉一致。

## 美术设计

- 主画面使用低视角 3D 方块表现，但整体包装成漫画书手绘风。
- 背景使用纸张纹理，UI 叠加细颗粒、斜向手绘线和网点阴影，让画面像画在纸上的动态漫画。
- 砖块是带粗黑描边的 3D Box，密集棋盘中保持规整正方形单元。
- 绿色普通砖使用柔和草绿色和少量共享色阶，降低大面积纯亮绿色带来的突兀感。
- 方格被消除时会立即从 Three.js 场景中移除，并播放纸色擦除粉尘和漫画爆线效果。
- 技能砖直接使用对应下落道具的同款漫画贴纸图标作为砖块外观，不再额外包一层彩色方块。
- 弹球使用面向镜头的清晰圆形贴片和贴近主体的黑色漫画描边，避免高速移动时出现低分段球体边缘残影。
- 下落道具由 Canvas 程序手绘为漫画贴纸图标，再作为 Three.js 透明贴图显示。
- `玩法说明` 页中的技能说明也使用同一套漫画贴纸图标，和技能砖、下落道具保持一致。
- 标题页、玩法说明、结算页和编辑器中的文字按钮统一使用同一套漫画书按钮规格，包括高度、圆角、黑色描边、阴影偏移和字体重量。

## 技术设计

- 使用 Three.js r162 和微信 Canvas 作用域适配器创建渲染环境，避免直接依赖浏览器 DOM。
- 使用 `THREE.WebGLRenderer`、`OrthographicCamera` 和 `CanvasTexture` 组合渲染 3D 场景与 2D UI。
- 弹球与砖块使用连续碰撞检测，按运动线段判断命中，避免高速弹球穿过灰色墙体或窄砖块。
- 弹球包含防卡死机制，连续墙体反弹或长时间困在小范围内时会自动纠偏，不会直接删除场内弹球。
- UI 画布使用独立高清像素比，并按状态变化、瞄准变化、消息变化和数值变化进行按需上传。
- 主循环按状态主动降帧：有弹球、道具、瞄准或完成动画时保持约 `60fps`，标题、说明、编辑和结算等静态页面降低刷新频率。
- Three.js 关闭对象排序，场景依靠固定层级组织渲染顺序，减少密集砖块网格每帧排序开销。
- 砖块使用共享几何体和材质；球体碰撞通过行列索引只检测运动轨迹附近的砖块，避免多球时每步扫描全场。
- 擦除粉尘和爆圈特效设置了同时存在数量上限，避免炸弹、激光等连锁清理时堆积过多临时网格和材质。

## 音频设计

- 背景音乐使用微信小游戏音频接口循环播放，开始一局时启动，胜利或失败进入结算时停止。
- 交互音效由 Web Audio API 实时合成，不依赖额外短音效资源。
- 射击、瞄准、挡板接球、墙体反弹、砖块破碎、道具掉落、道具触发、炸弹、激光、自动升级、关卡完成、编辑器放置和失败都有对应反馈。
- 高频事件带有播放节流，避免多球连撞时声音堆叠过载。

## 玩法说明设计

- 玩法说明页独立展示，不覆盖战斗画面。
- 说明内容覆盖瞄准、生命、灰墙反弹、普通砖消除、复杂技能、自动升级、自定义关卡和失败条件。
- 说明文字会自动换行，避免在竖屏设备中溢出或遮挡按钮。
