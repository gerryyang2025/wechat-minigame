# Bad North Game

这是一个独立的微信小游戏原型，目标是实现紧凑型 3D 岛屿防御策略玩法。项目使用 Three.js/WebGL 渲染、Low-poly 岛屿场景、屏幕空间描边后处理、触摸优先的小队指挥、实时移动与战斗、远海登陆船、动态海水、敌人波次、屋舍防守，以及 Web Audio API 实时合成音效。

## 当前功能

- Low-poly 3D 岛屿：包含阶梯式棕灰地形、水墨描边悬崖、海岸雾气、屋舍、树木、岩石、船只、士兵、战斗特效和投射物。
- 参考 Bad North 的拉远全局战术视角，地图、悬崖、船只、屋舍和多支小队可以同时阅读。
- 实时岛屿防御循环，包含布防阶段和战斗阶段。
- 5 波敌人进攻，敌船从远海航道进入，靠岸时生成尾流、浪花和登陆泡沫。
- 支持小队选择、移动、镜头拖拽、缩放、按住旋转、重置视角、开战和主动技能。
- 非 UI 区域拖拽可平移镜头，双指缩放可查看角色细节，短按仍用于选择小队或下达移动命令。
- 小队和敌人都使用瓦片寻路，不使用简单直线插值，因此会绕开建筑，不能穿越建筑占用区域。
- 高低地切换使用平滑高度插值、小幅攀爬弧线、身体倾斜和士兵步态偏移，单位上下台阶时有更真实的移动表现。
- 一格高度差的地形边缘会生成少量木梯，梯子位置会避开建筑，避免遮挡。
- 当前选中小队的移动路径会以单层 3D 虚线和节点环显示在地形上，避免重复叠线。
- 敌人攻击路线提示已在渲染层关闭；敌人 AI 仍在内部使用相同的目标选择和寻路逻辑。
- 自动战斗支持近战、箭矢、飞刀和星能球。
- 远程小队命中敌人后，敌人会短暂仇恨射手并前进寻求近战，而不是无视远程攻击。
- 敌人与玩家小队近战接触后会锁定彼此，冷却期间保持站位，并显示攻击/受击动画脉冲与碰撞特效。
- 建筑血条默认隐藏；建筑受伤后短暂显示 3D 血条和屏幕空间 `当前/最大` 文本。
- 屋舍全部被摧毁则失败，清完所有波次则胜利。
- 通过 `wx.setStorageSync` 保存本地最佳波次。
- WebGL 启动失败时会在 Canvas 上显示错误信息，并输出 `[bad-north-game] boot failed:` 日志。

## 美术风格

- 视觉目标是“三渲二手绘策略风”：Low-poly 几何、无导数水墨 Shader、网格外扩墨线壳和屏幕空间描边共同工作，不依赖照片贴图或真实 PBR 材质。
- 构图采用拉远的等距岛屿视角，玩家可以一眼读到战场、海岸线、屋舍、船只和所有小队。雨线与海岸雾让画面更接近阴雨水彩参考。
- 岛屿由块状阶梯地形、简化屋舍、塔式礼拜堂、船、岩石、针叶树和小队集群组成。角色仍保持低多边形，但增加了四肢、腰带、靴子、面部墨痕、衣褶、装备和墨线细节。
- 调色按玩法层级区分：冷蓝绿色海水、暖赭色地面、灰色悬崖和石面、白色海岸边线、纸感雾气，以及更饱和的兵种颜色。
- 友方单位具有清晰职业识别：民兵是棕褐布衣、腰带、靴子、剑和木盾；弓箭手是绿色兜帽、箭袋、箭羽、弓握把和弧形长弓；游侠是深色面罩、披风、口袋和双匕首；武僧是金色法衣、腰带、念珠、护腕、拳头和光环；星使是蓝白星光披风、法杖和发光星球。
- 敌人使用独立的黑红敌对语言：尖角兜帽、红色面纹与胸纹、尖刺肩甲、破损裙甲、深色四肢、强化墨线壳、黑盾和红色背旗。
- 材质 Shader 提供阶梯光照、程序化水洗颗粒、暗面墨色聚集、轻微纸色混合和逐材质饱和度控制，让画面有手绘质感，同时保持海水、地面、建筑和角色的颜色区分。
- 描边分为两层：网格级背面外扩墨线壳提供稳定轮廓，低分辨率屏幕空间后处理提供柔和颜色边缘、纸色、笔刷噪声和暗角。
- 海水使用自定义 Shader，包含灰绿色水彩混色、受限顶点波动和 Three.js 泡沫线图层。海平面低于最低地形，避免低地在海水颜色和地面颜色之间闪烁。
- 敌船从远海进入战术视野，有轻微上下浮动、船尾泡沫、循环尾流和登陆浪花。每条航道区分船只停靠的水面 `shore` 点和敌人部署的陆地 `landing` 点。
- UI 保持克制战术风：顶部半透明状态卡、建筑受伤后的世界血条，以及底部紧凑工具栏。

## 兵种与敌人

- 民兵：棕褐布衣、腰带、靴子、简单面部墨痕、剑和木盾。攻击方式为近战剑盾，无主动技能。
- 弓箭手：绿色兜帽与斗篷、长弓、弓握把、背部箭袋、箭杆和浅色箭羽。每个存活弓箭手都会从自己的阵型位置射箭。主动技能 `Volley` 会让每个弓箭手发射三轮箭矢。
- 游侠：深色兜帽、面巾、披风、腰包、靴子和双匕首细节。攻击方式为远程飞刀。主动技能 `False Light` 会生成吸引敌人的诱饵灯塔。
- 武僧：金色法衣、腰带、护腕、念珠、拳掌细节和光环。攻击方式为近战拳击。主动技能 `Light Prison` 会生成范围控制区域并困住敌人。
- 星使：蓝白星光披风、披风边饰、星点、法杖和发光星球。攻击方式为远程星能球。主动技能 `Starburst` 造成大范围 AOE 伤害。
- 敌人：黑红袭击者轮廓，包含尖角兜帽、红色面纹/胸纹、破损护甲、深色四肢、尖刺和强化墨线。盾兵携带大黑盾和旗帜；跑者体型更小并使用双刀；袭击者使用长刀和背旗。

## 工程结构

- `game.js`：微信小游戏启动入口。
- `game.json`：竖屏游戏运行配置。
- `project.config.json`：微信开发者工具项目配置。
- `libs/three.js`：本地 Three.js r162 CommonJS 构建，使用 `.js` 扩展名以兼容微信模块加载器。
- `src/minigame-app.js`：平台生命周期、触摸分发、尺寸变化、分享钩子、渲染器创建和启动错误诊断。
- `src/three-scope.js`：微信 Canvas 作用域 Three.js 适配器，遵循官方 `createScopedThreejs(canvas)` 模式。
- `src/minigame-runtime.js`：Three.js 渲染、Shader 后处理、岛屿构建、角色网格、模拟状态、控制、波次、战斗、技能和 UI 合成。
- `src/audio.js`：Web Audio 实时合成环境声、UI 反馈、移动命令、船只登陆、敌人部署、武器攻击、命中、建筑受击、技能、胜利和失败音效。
- `src/utils.js`：Canvas 创建、几何辅助、存储辅助、文本适配和 Canvas UI 绘制工具。
- `scripts/validate.js`：JavaScript 语法和 JSON 校验。
- `scripts/smoke.js`：关键实现契约的功能冒烟验证。
- `scripts/runtime-sim.js`：模拟微信 Canvas/WebGL 环境，驱动真实游戏循环、波次、小队命令、技能、投射物和场景同步。

## 渲染方案

- 主画面使用 `THREE.WebGLRenderer` 渲染。
- Three.js 由 `src/three-scope.js` 在 `wx.createCanvas()` 之后创建；适配器为微信 Canvas 补齐事件、尺寸、`document.createElementNS`、Image 和 window 相关能力，再把作用域内的 `THREE` 传入 `BadNorthRuntime`。
- 岛屿瓦片使用平面化 `BoxGeometry` 阶梯地形，并区分草地、悬崖和海岸材质。
- 角色由低多边形基础几何搭建。弓箭手的弓使用 `QuadraticBezierCurve3` 和 `TubeGeometry`，箭由细圆柱箭杆和锥形箭头组成。
- 远程攻击会按可见士兵数量生成投射物，投射物记录发射小队，并按投射物数量拆分总伤害以保持平衡。
- 近战接触使用 `lockMeleeEngagement()` 和 `triggerMeleeBrawl()`：双方锁定同一目标、停止冷却期间的路径抖动、面向彼此、触发攻击/受击变形，并生成由斩击面片和地面冲击环组成的 `clash` 特效。
- 固体对象使用 `makeLowPolyMaterial()` 创建无导数 `ShaderMaterial`，避开微信环境中容易出错的 `MeshToonMaterial`、`flatShading`、`fwidth()`、`dFdx()` 和 `dFdy()` 路径。
- 低多边形材质包含程序化水洗颗粒、阶梯光照、暗面墨色聚集、纸色混合和逐材质饱和度控制。
- 地形、建筑、树木、士兵和船只都添加网格级背面墨线壳，即使后处理不可用，直接渲染路径也有手绘轮廓。
- 海水使用自定义 `ShaderMaterial`，包含轻量顶点波动、灰绿色水彩混色和纸纹变化。
- `seaWaveGroup` 在水面上方添加真实 Three.js 泡沫线对象，随时间漂移，并与岛屿做深度测试。
- 敌船使用远海航道坐标生成，移动时通过 `emitBoatWake()` 添加成对尾流；到岸后停在水面 `shore` 坐标，产生 `splash` 与 `landingWake`，再把敌人部署到陆地 `landing` 坐标。
- 后处理优先尝试低分辨率 `WebGLRenderTarget`，再用全屏 `ShaderMaterial` 进行屏幕空间墨线、纸色、笔刷噪声和暗角处理。
- 描边 Shader 结合颜色边缘检测和可选深度边缘检测；微信运行时默认使用颜色边缘路径，深度纹理路径保留但不默认启用。
- 如果受限 WebGL 环境无法使用后处理渲染目标，会自动回退到直接 `scene + UI` 渲染。
- UI 绘制在离屏 Canvas 上，并通过 `THREE.CanvasTexture` 合成到 WebGL 场景上。
- 建筑血条是受击触发式显示，`damageHouse()` 改变 HP 后会打开一个短暂显示窗口。
- UI 纹理使用 `LinearSRGBColorSpace`，避免微信原生 Canvas 对象触发 Three.js 的 sRGB 转换警告。

## 移动、碰撞与 AI

- 移动基于岛屿瓦片图。命令会转成四方向相邻瓦片上的 A-star 风格路径，而不是直接直线插值。
- 建筑占用区域带有角色碰撞余量。点击建筑阻挡瓦片时，会自动重定向到附近可达空地。
- 路径允许受控的一格高度差，并拒绝过陡跳跃，防止悬崖被误用为捷径。
- 地形构建会收集一格高度差边缘作为梯子候选，根据可读性评分后只保留少量间距合适的梯子。
- 角色显示高度从当前路径段计算，不直接用 `round(x/z)` 贴瓦片；上下高度时会缓动、加小弧线并记录攀爬方向。
- 小队和敌人网格会根据移动状态面向行进方向，上下台阶时略微倾斜，并播放单兵步态偏移。
- 路径预览是贴合地形的 3D 虚线，不是 2D 叠加直线。每段虚线会在起点与终点高度之间插值，并在高度变化时加入小弧线。
- 友方路径预览只使用一层柔和米色虚线和青绿色节点环，避免双线重叠。
- 敌方攻击路线预览已在渲染层关闭，`enemyPathGroup` 在同步时会被清空。
- 敌人在接近小队、诱饵和建筑时使用同一套导航层。攻击建筑时会选择建筑外侧的可达攻击瓦片，而不是走向建筑中心。
- 敌人在确定建筑攻击点前，会同时扫描 A-star 计划路径 `findSquadDefendingRoute()` 和更宽的前方目标走廊 `findSquadAheadOfObjective()`。玩家小队只要站在敌人与建筑目标之间，就会被视为防守者并被主动攻击。
- 远程投射物命中会调用 `markEnemyRangedAggro()`，让受击敌人短暂把射手作为目标，并向弓箭手、游侠或星使靠近进入近战。
- 如果玩家小队拦截敌人当前路径的接下来几段，敌人会从建筑目标切换到小队接触战。双方使用小范围接触攻击距离，避免重叠、互相推挤或路径冻结。
- 敌人跟随有效建筑攻击路线时，不会对静态建筑目标做高频周期重算。若敌人停止前进，卡住计时器会清理缓存攻击瓦片并重新寻路。

## 音频方案

- 不需要音频文件。
- `src/audio.js` 优先使用 `wx.createWebAudioContext()`，并回退到 `AudioContext` 或 `GameGlobal.AudioContext`。
- 环境声使用振荡器、滤波器和增益包络合成。
- 命中、海浪、船只登陆、木材破裂和战斗冲击使用 `createBufferSource` 生成噪声缓冲。
- 武器音效按攻击类型合成：近战和拳击使用低频扫音加冲击噪声，箭矢和飞刀使用短高频扫音，星能使用明亮的多层振荡器。
- 主动技能有独立声音特征：弓箭手连射、游侠伪光、武僧光狱、星使星爆。
- UI 选择、命令、冷却拒绝、胜利和失败使用短振荡器提示音。

## 操作方式

- 点击小队卡片或岛上的小队可选中该小队。
- 战斗中再次点击已选小队卡片可触发主动技能。
- 点击岛屿瓦片可让当前小队实时移动。
- 在非 UI 区域拖拽可平移全局镜头。
- 双指捏合可放大查看角色细节或缩小查看全局战术视野。
- 短按岛屿瓦片用于移动命令；拖拽只用于镜头检查，二者不会冲突。
- 自定义视角按钮位于底部工具栏，不占用微信右上角胶囊区域。靶心按钮用于重置方向、平移和缩放；弧形箭头按钮按住后会持续朝一个方向旋转视角。
- 布防阶段点击底部 `开战` 或 `下一波` 开始下一次敌人登陆。

## 运行方式

1. 在微信开发者工具中打开 `bad-north-game`。
2. 如需配置 AppID，可复制 `project.private.config.example.json` 为 `project.private.config.json` 并填写自己的 AppID。
3. 在微信开发者工具中编译或预览小游戏。
